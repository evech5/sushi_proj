# SUSHKA — Система онлайн-доставки суши

Это полнофункциональное веб-приложение для доставки еды, включающее личный кабинет пользователя, админ-панель для управления товарами/категориями и панель для кухни для обработки заказов.

## Описание проекта
Приложение построено на связке Node.js (Express) и SQLite. Данные о товарах, категориях и заказах хранятся в реляционной базе данных. Система поддерживает разграничение прав доступа: Клиент, Кухня и Администратор.

## Технологический стек
*   **Backend**: Node.js, Express.js
*   **Database**: SQLite3
*   **Frontend**: HTML5, CSS3 (Grid/Flexbox), Vanilla JavaScript

## Структура проекта
*   `/backend` — серверная часть и API контроллеры.
*   `/frontend` — клиентская часть (статические файлы).
*   `dataBase.db` — файл базы данных SQLite.

## Установка и запуск

### Предварительные требования
*   Установленный [Node.js](https://nodejs.org/) (версия 16+).

### Инструкция
1.  Клонируйте репозиторий.
2.  Установите зависимости в корне проекта:
```bash
    npm install express sqlite3
    ```
3.  Запустите сервер:
```bash
    node backend/app.js
    ```
4.  Откройте приложение в браузере по адресу: `http://localhost:3000`

## Функциональные возможности
*   **Пользователь**: Регистрация/вход, выбор адреса через интерактивную карту (OpenStreetMap), оформление заказов, история заказов.
*   **Кухня**: Просмотр входящих заказов, изменение статуса приготовления (Новый -> Готовится -> В пути -> Завершен).
*   **Администратор**: Управление категориями товаров и редактирование меню.

## Интеграция базы данных
Проект использует автоматизированные миграции. Основные таблицы:
*   `users` — хранение данных пользователей и их статусов.
*   `products` — каталог товаров.
*   `categories` — иерархия категорий с поддержкой русских локализаций (`ru_name`).
*   `orders` / `order_items` — обработка заказов.
